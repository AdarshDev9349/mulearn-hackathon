
# MuLearn Hackathon Website

**Live URL:** [mulearn-hackathon.vercel.app](https://mulearn-hackathon.vercel.app)  
This is the official website for the **MuLearn Hackathon**, built with **React**, **Vite**, and enhanced with **Framer Motion** and **Vanta.js** for beautiful effects and smooth user experience.

---

## Features

- Animated and visually engaging landing page
- Smooth scroll navigation and intersection effects
- Interactive elements with Framer Motion and Vanta.js
- Integration with backend via Axios
- Performance insights using Vercel Speed Insights

---

## Tech Stack

- **React 18**
- **Vite**
- **Framer Motion**
- **Vanta.js & Three.js**
- **Axios**
- **React Router DOM**
- **Tailwind CSS**
- **Heroicons & Headless UI**

---

## Project Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AdarshDev9349/mulearn-hackathon.git
cd mulearn-hackathon
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to view the app locally.
